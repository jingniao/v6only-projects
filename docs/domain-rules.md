# 域名清单

UTF-8 文本，一行一条。允许空行、整行 `#` 注释及空格或制表符后的行内注释。支持 LF 和 CRLF，拒绝其他控制字符。注释可含中文；域名只接受 ASCII。

统一小写、移除一个末尾点，去重并排序。根域与通配规则分别保留。`openai.com` 只匹配自身；`*.openai.com` 匹配 `api.openai.com`、`a.b.openai.com`，不匹配 `openai.com`、`abcopenai.com`、`openai.com.evil.example`。

当前要求至少两个标签，不接受 `localhost` 等单标签主机名；标签长度 1–63，完整域名不超过 253 字节（不计 `*.` 和可选末尾点）。只接受 ASCII 字母、数字、连字符，标签首尾不得为连字符。拒绝 URL、IP、端口、路径、空白、下划线和中间星号。合法 DNS 名称不代表存在 DNS 记录或支持 IPv6。

`xn--` 标签使用 Python 标准库 IDNA 编解码往返校验。该库使用 IDNA 2003，不是完整 IDNA 2008/UTS #46 实现；某些新标准允许的标签会被保守拒绝。首版不接受直接输入 Unicode 域名。

导入先校验完整内容再写入，错误只报告行号和错误类别，不回显可能带凭据的原文。`add/remove` 接收纯规则参数，不接受注释语法。输入上限 4 MiB，不使用 eval、shell 拼接或网络查询。

规则已接入两个后端。sing-box 使用锚定正则表达仅子域；dnsmasq 通过根域/子域独立分派保真。不能直接把包含根域的后缀匹配当作仅子域通配。
